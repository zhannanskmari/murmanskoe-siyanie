04 / Помощь с сайтом

Вопросы и ответы

Как открыть рецепт и покупки?

Выберите день. В карточке блюда раскройте «Открыть рецепт». Под карточками расположен список покупок этого дня.

Откуда взяты ингредиенты и калорийность?

Из предоставленного октябрьского меню, подтверждённого Жанной. Покупки сгруппированы по рецептам каждого дня. Указанные значения калорийности сохранены без пересчёта.

Где рекомендации и ответы Юлии о программе?

Они пока не предоставлены. Этот раздел содержит только помощь по использованию сайта. Ответы о программе будут добавлены после согласования с Юлией.

Можно ли задать вопрос через эту форму?

Форма ниже учебная: она показывает подтверждение только на вашем экране. Сообщение никому не отправляется, не сохраняется и исчезает при обновлении страницы. Актуальная ссылка для связи с Юлией пока не подтверждена.
